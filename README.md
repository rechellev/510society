# 510 Society

The 510 Society website: Home, Events, About and Partner with 510.

- Hosted on GitHub Pages from this repository.
- `data/events.json` and `assets/img/sp/` update automatically from Sweatpals every 6 hours (`.github/workflows/sync-events.yml`). You can also run it by hand from the Actions tab.
- `data/partner-notes.json` holds hand-written partner details for past events. The sync never overwrites it.
- Partner inquiries are emailed to 510societyy@gmail.com through FormSubmit. The first inquiry sends an activation email to that inbox; click Activate once.
- Analytics: GoatCounter at https://510society.goatcounter.com (cookie-free).
- The Partner one-pager PDF lives at `assets/510-society-partner-one-pager.pdf`.
